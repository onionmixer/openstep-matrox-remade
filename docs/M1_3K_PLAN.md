# M1-3k — 깊이 매핑의 정렬을 고치고, 정착 읽기를 조건부로 만든다

두 가지를 한 묶음으로 한다. 앞엣것은 유저랜드라 재부팅이 없고, 뒤엣것은
드라이버라 재부팅이 필요하다. **앞엣것을 먼저 고쳐 검증하고, 그 다음
드라이버를 고쳐 재부팅을 한 번만 쓴다.** 아직 코드 없음.

## A. §3-20 — 깊이 매핑이 4 KiB 로 정렬한다 (유저랜드)

### 무엇이 틀렸나

```c
/* mesa/OpenStepMGAMesaBuffer.c */
tail = (tail + 4095UL) & ~4095UL;      /* 오프셋 */
need = (need + 4095UL) & ~4095UL;      /* 길이 */
```

이 기계의 페이지는 **8192** 이고(`vm_page_size` 와 `getpagesize()` 둘 다
8192 로 확인), 페이지 정렬이 아닌 오프셋은 **`EINVAL` 로 거절된다**
(§3-19 를 재면서 오프셋 × 길이 행렬로 직접 확인: +4096, +12288 은 길이와
무관하게 전부 거절).

**처음 계산은 전제가 틀렸다** — 보폭을 디스플레이 보폭으로 놓았는데, 이
경로는 `bufStride != bufWidth` 면 아예 안 타므로 보폭이 곧 버퍼 너비다.
다시 셌다: `h*w*4` 가 8192 의 배수인 것은 `h*w` 가 2048 의 배수일 때뿐이고,
너비 1..1024 × 높이 1..768 의 786432 조합 중 **395172 개(50.2%)가 실패한다.**
**800×600 과 320×240 이 지금 하드웨어 깊이를 못 쓴다**; 시험이 늘 1024×768
이라 안 걸렸을 뿐이다.

실패하면 `OpenStepMesaAccelDepthBuffer` 가 0 을 돌려주고 Mesa 는 **말없이**
소프트웨어 깊이 버퍼로 되돌아간다. 그림은 맞고 가속만 조용히 사라진다.

### 고침

- `4095` 두 곳을 **`vm_page_size`** 에서 유도한 값으로 바꾼다. 그 파일은
  이미 `vm_allocate` 때문에 Mach 를 들이고 있으므로 새 의존이 없다.
- 상수를 박지 않는다. 8192 라고 적으면 이 기계에서만 맞는 코드가 된다.
- 정렬 산식은 `(x + (p - 1)) & ~(p - 1)` 이고, `p` 가 2 의 거듭제곱임을
  전제한다. **전제를 코드에 적고, 아니면 매핑을 포기한다** — 조용히 틀린
  주소를 쓰는 것보다 낫다.
- **말없이 물러나지 않는다.** 깊이 매핑이 실패하면 한 번만 알린다.
  지금은 0 을 돌려주고 끝이라, 하드웨어 깊이가 사라진 것을 아무도 모른다.

### 검증 (재부팅 없음)

- 짝수 높이(768)와 **홀수 높이**(767, 769)로 깊이 매핑을 시도해, 고치기
  전에는 홀수가 실패하고 고친 뒤에는 셋 다 성공하는지 본다.
- 계산은 python 으로 미리 하고, 실기 결과와 대조한다.

## B. M1-3j — 정착 읽기를 조건부로 (드라이버, 재부팅 1 회)

### 술어 — 검증기가 이미 증명한 것에서 유도한다

검증기는 `dstorg >= 창시작` 과 넘침 없음을 이미 증명한다. 그 아래에서는
"쓰기 범위가 창의 첫 64 바이트에 닿는가" 가 **비교 하나로 줄어든다** —
앞으로만 나아가는 범위는 죽은 구간 뒤에서 시작하면 뒤로 못 닿기 때문이다.

python 으로 확인했다: `org` 를 창 시작부터 8192 까지 4 바이트씩, 보폭·행수
다섯 조합, **10240 가지에서 범위 검사와 `org - WS < 64` 가 한 번도 안
갈렸다.**

```
색   : (dstorg - windowStart) < 64
깊이 : (zorg   - windowStart) < 64        -- 어떤 삼각형이 ZI 일 때만
```

`anyZI` 는 검증기·인코더가 쓰는 것과 **같은 식**으로 구한다.
**스냅샷과 검증을 마친 뒤에** 계산한다.

### 손잡이의 상태를 셋으로

지금은 `0 = 끔`, `N = 워드 N-1 을 항상 읽음` 두 가지다. 출시하려면 세 번째가
필요하다.

| 값 | 뜻 |
| --- | --- |
| `0` | 완전히 끔 |
| `1..probeWords` | **강제**: 성공한 모든 제출 뒤 워드 N-1 을 읽음 (측정 재현용) |
| `OSMGA_HW3D_SETTLE_AUTO` | **기본값**: 겹칠 때만, 워드 16(바이트 64)을 읽음 |

기본값이 `AUTO` 여야 하므로 전역의 초기값을 그렇게 둔다. `0` 이 초기값이면
부팅 직후가 "끔"이 되어 버린다.

워드 16 은 훑기에서 **처음으로 통한** 자리다. 그보다 멀리도 전부 통했으므로
여유를 더 둘 수도 있지만, **측정된 값을 쓰고 그 사실을 적는다.**

### 셈을 하나 둔다

자동 읽기가 몇 번 일어났는지 센다. 세터가 불릴 때 그 수를 함께 알린다.
새 표면을 만들지 않고, **조건부가 정말 조건부인지** 확인할 수 있다 —
안 겹치는 목적지로 돌린 뒤 셈이 안 늘면 그렇다.

### 검증 (재부팅 뒤, 모드 5 로 설정마다 80 시행)

| 설정 | 목적지 | 예상 |
| --- | --- | --- |
| 강제 끔 | 창 시작 | 80/80 짧음 |
| 강제 워드 0 | 창 시작 | 80/80 짧음 |
| 강제 워드 16 | 창 시작 | 0/80 |
| **자동** | **창 시작** | **0/80**, 셈이 는다 |
| 자동 | 한 페이지 아래 | 0/80, **셈이 안 는다** |

마지막 줄이 조건부임을 보이는 줄이다.

## C. 안 하는 것

- **원인을 안다고 적지 않는다.** 왜 64 바이트인지, 왜 창 시작 한 자리인지
  모른다. 경험적 고침이고 그렇게 적는다.
- **다른 MGA 부품으로 일반화하지 않는다.** 이 G450/OPENSTEP 구성에서 쟀다.
- **무조건 읽기를 기본으로 하지 않는다** — 비용을 안 쟀다. 손잡이의 강제
  모드가 남아 있으므로 나중에 잴 수 있다.
- **§3-19 관련 코드는 안 건드린다.** 철회됐다.
