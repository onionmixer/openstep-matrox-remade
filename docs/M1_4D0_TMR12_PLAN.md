# M1-4d0 — 검증기가 `TMR1`/`TMR2` 를 뒤바꿔 읽는다 (계획, 2026-08-23)

**코드는 아직 안 고쳤다.** 이 문서가 교차검토 대상이다.

## 1. 무엇이 어긋나 있나

**빌더**(`OpenStepMGAMesaTriangle.c:454-457`)는

```
   tmr[0] = u 의 dx        tmr[1] = u 의 dy
   tmr[2] = v 의 dx        tmr[3] = v 의 dy
```

로 쓰고, 그 옆에 **측정 근거**가 붙어 있다 — 반대로 두면 소프트웨어 경로와
4410 화소 중 2157 이 어긋나고, 이대로 두면 0 이다.

**검증기**(`OpenStepMGAHW3D.c`)는 반대로 읽는다:

```
   513-516   tmr[1] 을 x 폭으로, tmr[2] 를 y 높이로 묶는다
   538-539   u 에 tmr[2]·dy 를,  v 에 tmr[1]·dx 를 더한다
   568-572   행 걷기에서도 같다
```

## 2. 측정으로 확인했다

`ds/dy` 를 크게(`COORD_MAX/16`) 주고 `dt/dx = 0` 으로 32 행을 그리면, 올바른
읽기에서는 u 가 상한을 넘으므로 **거절**되어야 한다.  실측 **verdict 0 —
통과**한다.  검증기가 `tmr[2]`(=0)를 u 의 y 기울기로 보기 때문이다.

## 3. 무엇이 위험한가, 그리고 무엇은 아닌가

* **주소 안전은 영향 없다** — 클램프/마스크가 색인을 텍스처 안에 붙잡는다.
* 깨진 것은 **"잰 범위 안에 머문다"** 는 규칙, 곧 검증기의 존재 이유다.
  좌표가 아무도 안 본 영역으로 나가도 거절되지 않는다.
* 지금까지 안 드러난 이유: 탐침 대부분이 `tmr[1] = tmr[2] = 0` 이고, GL 경로는
  실제로 범위를 안 벗어나므로 **통과 여부가 같았다**.

## 4. 내가 이 자리를 잘못 읽었던 것

이번 세션에서 나는 "검증기의 배치가 `mga_exa.c` 와 정확히 일치하므로
교차검증된다"고 적었다.  **틀렸다.**  `mga_exa.c` 는 `TMR1 = Y_incx`(= dt/dx)
라 하고 `mga_storm.c` 의 주석은 `TMR1 = "sy inc"`(= ds/dy)라 하여 **두 참고
소스가 서로 다르다**.  우리 빌더는 `mga_storm.c` 쪽을 따르고 **실기 측정으로
확정**했다.  나는 잘못된 읽기를, 하필 그 잘못과 같은 편인 참고 소스에 대고
확인했다.

## 7. 고쳤다 (재부팅 대기, 2026-08-23)

### 7-1 세 자리

```
   기울기 크기 검사   tmr[1] 을 높이로, tmr[2] 를 폭으로  (축을 따라간다)
   상자 경로          u 에 tmr[1]*dy,  v 에 tmr[2]*dx
   행 걷기            같은 자리 두 곳과 오른쪽 끝점
```

기울기 검사도 함께 바꾼 것이 중요하다 — 좌표 평가만 고치면 **범위 증명이
여전히 부실하다**(교차검토 지적, 검산: `u` 의 `dy` 로 인한 변위는
`|ds/dy| × 높이` 이므로 축을 따라야 한다).

### 7-2 헤더에 의미를 못 박았다

```
   u = tmr[6] + tmr[0]*dx + tmr[1]*dy
   v = tmr[7] + tmr[2]*dx + tmr[3]*dy
```

읽는 쪽은 **기억이 아니라 이 네 식**을 써야 한다.  참고 소스가 서로 다르다는
사실(`mga_exa.c` 대 `mga_storm.c`)도 함께 적었다 — 잘못된 읽기가 검사를
통과한 경로가 그것이었다.

### 7-3 회귀 시험

미분을 **하나씩만** 켜고 **폭 ≠ 높이** 인 도형으로, 자기 축에서는 범위를
벗어나고 다른 축에서는 안 벗어나는 기울기를 python 으로 골랐다
(`COORD_MAX/10`: 31 걸음이면 넘고 7 걸음이면 안 넘는다).

고치기 전 커널에서 실행하면:

```
   ok    ds/dx wide      verdict 1
   FAIL  ds/dy tall      verdict 0   <- 뒤바뀜이 잡힌다
   FAIL  dt/dx wide      verdict 0   <- 뒤바뀜이 잡힌다
   ok    dt/dy tall      verdict 1
```

**뒤바뀐 검증기는 각 쌍에서 정확히 하나씩 통과시킨다** — 예측한 무늬 그대로다.
고친 커널에서는 넷 다 거절되어야 한다.
