# M1-4cf — 원근을 쓸 수 있게 하는 두 경계 (계획, 2026-08-23)

**코드는 건드리지 않았다.** 이 문서가 교차검토 대상이다.

## 1. 측정이 준 것

* 제수는 **정확히 `q`** (열두 값에서 확인).  나눗셈기는 멀쩡하다.
* 분자에 붙는 것은 **`E = 512·f`** (`f` 는 `q` 의 정규화 가수), 지수와 무관,
  **`E ≤ 512`**.
* 텍셀 오프셋 = `4E/q ≤ 2048/q`.
* 사영 삼중항 `(s,t,q)` 는 λ 로 자유롭게 비례 가능(몫 불변).

**결론: `q` 를 크게 잡으면 오차가 저절로 사라진다.  보정 평면이 필요 없다.**

## 2. 그런데 그 해법을 막는 것이 둘 있다

### 2-1 `Q_MIN = 256` 은 8 텍셀까지 허용한다

`Q_MIN` 은 나눗셈기가 무너지는 자리가 아니라 **원하는 정확도**가 정한다:

| 원하는 오차 | 필요한 `q` |
|---|---|
| 1 텍셀 | 2048 |
| 1/4 텍셀 | 8192 |
| 1/16 텍셀 | 32768 |

지금의 256 은 근거 없이 고른 값이고 8 텍셀을 허용한다.

### 2-2 아핀 시절의 `|tmr[6]| ≤ 2^23` 이 큰 `q` 를 막는다

검증기는 `tmr[6]`·`tmr[7]` 을 `TEX_COORD_MAX = 2^23` 으로 묶는다.  아핀에서는
`tmr[6]` 이 **좌표 그 자체**였으므로 옳았다.  원근에서는 **분자**이고
`s = 좌표·q/65536` 이므로 `q` 가 커지면 `s` 가 커진다:

```
   좌표  8.5 텍셀, q = 2^23 -> s = 17,825,792   거절
   좌표 60   텍셀, q = 2^20 -> s = 15,728,640   거절
```

즉 이 경계가 §1 의 해법을 정면으로 막는다.  그리고 §46 이 `q = Q_MAX` 에서
거절된 이유도 이것이었다(그때는 원인을 몰랐다).

## 3. 선택지 (정하지 않는다)

| 안 | 내용 | 걱정 |
|---|---|---|
| (a) | 원근일 때 `tmr[6]`·`tmr[7]` 의 경계를 **비율 검사에 맡긴다**(`s ≤ 128·q` 는 이미 모서리마다 돈다) | 넘침 여유를 따로 세워야 |
| (b) | 원근일 때 경계를 `S_MAX` 로 넓힌다 (예 `2^28`) | 어떤 값이 맞는지 근거 필요 |
| (c) | 아무것도 안 바꾸고 `q ≤ 65536` 만 쓴다 | 오프셋 `2048/65536 = 1/32` 텍셀 — 사실 충분하다 |
| (d) | `Q_MAX` 를 `65536` 으로 낮춘다 | `q` 범위가 좁아져 깊이비가 제한된다 |

**(c) 가 유력해 보인다**: `q ≤ 65536` 이면 오프셋이 1/32 텍셀 이하이고,
`s ≤ 128·65536 = 2^23` 이라 기존 경계와 **정확히 맞아떨어진다**.  그러면
아무것도 넓히지 않고 `Q_MAX` 만 내리면 된다.  다만 `q` 의 허용 범위가
`[Q_MIN, 65536]` 이 되어 한 프리미티브 안의 깊이비가 `65536/Q_MIN` 로 묶인다 —
`Q_MIN = 2048` 이면 32:1, `Q_MIN = 8192` 면 8:1.

## 4. 넘침 여유 (어느 안이든 필요)

`ux = tmr[6] + tmr[0]·dx + tmr[2]·dy` 이고 기존 기울기 검사가 두 곱을 각각
`2^23` 이하로 묶는다.  python 으로 확인:

```
   |tmr[6]| ≤ 2^23  ->  |ux| ≤ 2^24.6   안전
   |tmr[6]| ≤ 2^28  ->  |ux| ≤ 2^28.1   안전
   |tmr[6]| ≤ 2^30  ->  |ux| ≤ 2^30.0   안전
```

### 6-1 근본 맞바꿈

```
   깊이비 R  ×  (1/오차)  =  256      (텍스처 하나를 쓰는 프리미티브)
```

레지스터 폭이 정하는 상수다.  `Q_MIN` 은 이 곡선 위 어디에 앉을지만 고른다:

```
   Q_MIN =  2048 -> 1     텍셀, 256:1
   Q_MIN =  8192 -> 1/4   텍셀,  64:1     <- 고른 값
   Q_MIN = 32768 -> 1/16  텍셀,  16:1
```

### 6-2 들어간 것

`Q_MIN` 을 **256 → 8192** 로. 근거는 측정이다(오차 ≤ `2048/q` 텍셀).

### 6-3 안 한 것과 그 이유

분자 경계(`|tmr[6]| ≤ 2^23`)를 원근에서 넓히면 곡선 전체가 좋아지지만,
**혼자서는 못 한다** — 기울기 경계가 아핀 시절 것(`tmr[6]` 이 좌표이던 때)이라
`q` 를 인식하도록 함께 바꿔야 한다.  그건 별도의 설계이고 별도의 검토다.
