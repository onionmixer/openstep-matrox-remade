## 1. T7' — 화소당 1 텍셀로 내린다

### 저장소가 이미 답한 것

**T3 가 화소당 정확히 1 텍셀**이다 — 64 텍셀 맵의 8..56 을 48 화소에 걸쳤다.
그 조건에서 **위상 1·2·3 이 1176/1176 정확**했다.  곧 **WARP 주소지정은 그
비율에서 이미 증명돼 있다.**

지금 T7 은 **화소당 4 텍셀**이다.  반 화소 앵커 오차가 **2 텍셀**을 움직이고
그것이 빈 폭이라, 하드웨어가 무엇을 하든 판정이 안 선다.  실제로 **클램프
대조군까지 360 화소 틀렸다** — 하드웨어가 아니라 지도가 틀렸다는 증거다.

### 설계

```
맵      16 x 16, pitch 16          (2 의 거듭제곱, pitch == width)
sweep   3 주기 = 48 텍셀 / 48 화소 = 화소당 1 텍셀   <- T3 와 같은 예산
위상    T3 처럼 네 위상 밴드 (0, 1/4, 1/2, 3/4 텍셀)
축      U 만 / V 만 / 둘 다, 나머지 축은 범위 안에 고정
대조군  같은 좌표로 clamp 켠 밴드
판정    잡아둔 축은 정확, sweep 축은 히스토그램 1 개 빈
```

**T7e 는 그대로 둔다** — 이미 답했고 앵커에 무관하다.

## 2. T8a' — 비트 하나

### 저장소가 이미 답한 것

`docs/D3_4_TEXTURE_PLAN.md:160` 이 적어 놨다:

```
ALPHACTRL = 0x00000101 = MGA_ALPHACHANNEL(0x100) | SRC_ONE(1) | DST_ZERO(0)
mga_reg.h:587, :596, :605
```

하네스는 `0x0001` 을 쓴다 — **`ALPHACHANNEL` 이 없다.**  그 비트가 없으면
알파가 목적지에 안 써지고, **T8b 가 그것을 증명한다**(거기서는 `0x01000154`
로 알파가 정확히 블렌딩돼 나왔다).

그리고 하네스의 주석은 그 값을 *"Mesa's own initial value"* 라고 부르는데,
Mesa 의 값은 `OSMGA_MESA_BLEND_OPAQUE = 0x00000101`(`Triangle.h:113`)이다.
**주석도 틀렸다.**

### 사양서가 기전까지 말해 준다 (3-33 ~ 3-34, 회신 전 직접 확인)

비트 `<9:8>` 은 `alphamode` 이고 **"프레임 버퍼에 써질 알파 모드를 고른다"**:

```
'00'  FCOL              <- 0x0001 이 이것이다
'01'  alpha channel     <- 0x0101 이 이것이다
'10'  video alpha
```

곧 `0x0001` 에서 목적지에 써지는 알파는 **`FCOL` 의 알파**이고, 하네스는
상태 목록에서 **`FCOL` 을 0 으로 쓴다.**  그래서 T8a 가 두 밴드 모두
`alpha 0..0` 을 읽었다 — `TDUALSTAGE` 선택자와 무관하게, **알파가 애초에
`FCOL` 에서 왔기 때문**이다.

### 설계

```
OSMGA_M3_ALPHACTRL_NOBLEND  0x0001 -> 0x0101
```

### 모든 밴드에 걸쳐 안전한가 — 확인했다

`alphamode` 는 **프레임 버퍼에 써질 알파만** 정한다.  `srcblendf=ONE`,
`dstblendf=ZERO` 는 그대로이고, 사양서가 *"To disable alpha blending,
srcblendf must be programmed with 1 and dstblendf with 0"* 라고 적는다 —
**블렌딩은 여전히 꺼져 있다.**  RGB 출력은 한 비트도 안 바뀐다.

그리고 표면을 읽는 밴드는 **전부 알파를 마스크로 버린다**:

```
osmgaM3CheckShape / CompareSurfaces / ReportTexture
osmgaM4ReportWrap / ReportProjTex / ReportClamp     -- 모두 & OSMGA_D2E_RGB
osmgaM4ReportAlpha                                  -- sentinel 비교도 마스크
osmgaM4CompareARGB (T8b)                            -- 32 비트 전부이지만
                                                       T8b 는 블렌드 값을 쓴다
```

→ **T0~T6 의 판정은 바뀌지 않는다.**

⚠ 이것은 **모든 밴드**의 값이다.  T0~T6 의 그림은 안 바뀐다(src ONE /
dst ZERO 는 그대로이고 블렌딩은 여전히 없다) — 바뀌는 것은 **알파가 써지는
것뿐**이다.  그래도 T0 의 오라클 대조는 알파를 마스크로 버리므로 영향이 없다.

## 3. T8b' — 오라클이 블렌딩하게

오라클은 `MGA_DWGCTL_SOLID_FILL` 이라 `ALPHACTRL` 을 보지 않는다.  실기가
그것을 보여줬다 — 오라클이 **소스 색을 그대로** 썼다(`80ff8040`).

선택지 둘:

```
(a) 오라클을 Gouraud/atype I 로 바꾼다      기존 T0·T6 의 판정을 건드린다
(b) 오라클을 빼고 계산된 기대값과 비교한다   산술이 이제 확정됐다
```

**(b) 를 고른다.**  T8b 가 이미 산술을 확정했기 때문이다 — 반올림이고,
알파 채널도 블렌딩되며, python 으로 네 채널이 전부 맞았다.  오라클을 고치면
T0·T6 이 쓰는 함수를 건드리게 되고, 그 둘은 지금 통과하고 있다.

```
판정  WARP 픽셀 == round((src*a + dst*(255-a)) / 255)  채널 넷 전부
      기대값은 커널에서 정수로 계산한다 (a 는 상수라 나눗셈 하나)
대조  블렌딩 끈 밴드도 함께 -- 그때는 소스가 그대로 나와야 한다
```

### 9.1 T7 — repeat 가 축마다 감긴다 ✅

**세 축 모두 네 위상 중 하나만 실패.**  판정 기준이 `≤1` 이었고, 그 이유는
T3 다: 위상 0 은 `u = −1.0` 정확히 **텍셀 경계**이고, T3 가 같은 자리에서
`1 exact / 1175 wrong` 을 냈다.  앵커가 경계 바로 아래 있다는 이미 아는
성질이지 결함이 아니다.

화소당 4 텍셀에서는 **클램프 대조군까지 360 화소 틀렸다.**  1 텍셀로 내리자
세 축이 전부 깨끗해졌다 — 하드웨어는 처음부터 옳았고 지도가 틀렸다.

### 9.2 T7e — 이음매도 감긴다 ✅

```
u near 127  far 128 | v near 127  far 128 | corner 127 127
```

전부 반반 블렌드.  `0` 이나 `255` 가 하나도 없다 — 이웃 탭이 클램프됐다면
그 값이 나왔어야 한다.  `M1_4CB §8-2` 가 사다리꼴에서 잰 것과 같은 자리다.

### 9.3 T8a — 선택자가 실제로 고른다 ✅

```
diffuse (ARG2)  alpha 0..249      <- 보간 알파.  기대값 255*47/48 = 249 (python)
fromtex (ARG1)  alpha 51..51      <- 텍스처의 0x33, 전 화소
```

`ALPHACTRL` 의 `alphamode` 를 `FCOL` 에서 `alpha channel` 로 바꾸자 밴드가
처음으로 자기 질문을 물었다.  **두 밴드가 확실히 다르다** — NOT EXERCISED 가
아니다.

### 9.4 T8b — 블렌딩이 계산과 정확히 맞는다 ✅

```
wrong 0
```

세 조건 전부: 덮인 화소가 채널 넷에서 `((c·a + d·(255−a)) + 127)/255` 와
일치, 덮인 화소가 프리필에서 벗어남, 삼각형 밖은 프리필 유지.

### 9.5 T9 — 런 사이 펜스는 필요 없다 ✅

```
busy 1   leak 0 0
```

`busy 1` 이 전제가 충족됐음을 말한다 — run A 가 아직 그리는 중이었다.
그 상태에서 두 번째 GENERAL 목록이 펜스 없이 나갔고 **깊이가 새지 않았다.**
흩뿌린 삼각형으로 다시 재도 같다.

### 9.6 이것이 여는 것

```
osmgaHW3DWarpAdmits   repeat 거절을 푼다      (T7, T7e)
                      블렌딩 거절을 푼다      (T8b)
M6 §4                 런마다 펜스를 뺀다      (T9)
```

**WARP 자격검증이 끝났다.**
