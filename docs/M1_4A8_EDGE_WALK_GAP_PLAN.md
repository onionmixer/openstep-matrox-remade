# 확정했다던 변 걷기가 어떤 레지스터에서 깨진다 (계획, 2026-08-21)

`M1_4A7_DEPTH_FIX_PLAN.md` §9-2 에서 나온 것. 깊이 수정은 **이것이 풀릴
때까지 보류**한다.

## 1. 무엇이 어긋났나 — 지금까지 확보한 사실

도형 4 `(265,10) (313,152) (146,139)`. 빌더가 내놓는 레지스터를 **직접
찍었다**:

```
   [0] y=10 h=129  FXBNDRY left=265 right=265  SGN=2
       AR0=258 AR1=-229 AR2=-238 | AR6=284 AR4=-2 AR5=-96
   [1] y=139 h=13  ... (이쪽은 13/13 정확하다)
```

| 사실 | 근거 |
|---|---|
| 빌더는 맞다 | 호스트 시험에서 규칙과 **0 행 차이**, 커널도 통과 |
| 드라이버는 레지스터를 **그대로** 보낸다 | `MGA_AR0..AR6, MGA_SGN` 을 무가공 전달 |
| 깊이와 무관하다 | 깊이를 꺼도 11629 화소로 동일 |
| 소프트웨어는 맞다 | 규칙 대비 누락 2, 초과 0 |
| **사다리꼴 1 은 맞다** | 13/13 |
| **사다리꼴 0 만 틀리다** | 129 행 중 63(=model k) / 62(=model k+1) |

**모양은 오프셋이 아니라 속도 차이다:**

```
   하드웨어  왼쪽 264 -> 146  (118 열)   오른쪽 266 -> 308  (42 열)
   레지스터  왼쪽          119 열        오른쪽          43 열
```

시작은 **한 열 앞서고**, 끝은 **같다**. 즉 걸음 수가 하나 적다.

## 2. 반증된 가설 (다시 세우지 않기 위해 적는다)

| 가설 | 반증 |
|---|---|
| 깊이의 ZI access type | 깊이를 꺼도 같다 |
| 정점 y 가 정수 아래로 떨어짐 | 단정도로 계산해도 정확 |
| 삼각형이 한 행 밀림 | 하드웨어가 규칙의 **상위집합** |
| 첫 행이 빈 행(`left==right`) | 도형 3 도 그런데 정확하다 |
| 배수 조건이 `a<=0` | 74/129 |
| 시드가 다름(`AR1` 대 `AR1-AR2`, 0 행 배수 여부) | **전수 탐색해도 최고 105/129** |
| 드라이버가 `AR1` 을 덮어씀 | 소스 확인, 그대로 보낸다 |

## 3. 그래서 추측을 멈추고 **레지스터 공간을 훑는다**

지난번 변 걷기 탐침은 **세 점**만 봤다(`AR1!=AR2` 하나, 대조군 둘). 그
세 점이 전부 맞았기 때문에 규칙을 "확정"이라고 적었다 — **그게 과했다.**

이번에는 raw `hw3d` 클라이언트로 **격자**를 훑는다. Mesa 를 끼우지 않으므로
빌더·훅·클리퍼가 전부 빠지고 남는 것은 엔진뿐이다.

- 왼쪽 변은 세우고, 오른쪽 변에 `(AR6, AR4, AR5)` 를 넣는다. 시작 열이
  같으므로 **그려진 화소 수 = 그 행의 걸음 수**다.
- 격자: `mag` 와 `dy` 를 여러 비율로, `e` 를 `[-(dy), dy]` 범위에서.
  **도형 4 의 값(`AR6=284 AR4=-2 AR5=-96`, h=129)을 반드시 포함**한다 —
  가장 먼저 확인할 것은 "raw 로도 재현되는가" 이다.
- 각 조합마다 **행마다** 모델과 비교하고 **첫 어긋난 행**을 찍는다.
  총합이나 비율이 아니라 어디서 갈리는지가 필요하다.

## 4. 먼저 답할 질문 하나

**raw 트라페조이드로 도형 4 의 레지스터를 그대로 보내면 재현되는가?**

- 재현되면: 엔진의 문제이고 격자로 규칙을 다시 세운다.
- 재현 안 되면: Mesa 경로에서 무언가가 더 붙는 것이고(배치 안 다른 삼각형,
  상태 잔류, DMA 순서), 그쪽을 판다.

이 하나가 조사의 방향을 가른다. **먼저 이것만 한다.**

## 5. 한 번에 하나씩 바꾼다

도형 4 의 조합에서 `AR4` 만, `AR6` 만, `h` 만 바꿔가며 어느 축에서 모델이
깨지는지 좁힌다. 격자 전체를 먼저 돌리면 결과가 많아 읽지 못한다.

## 6. 커널 검증기도 같은 모델을 쓴다

`OpenStepMGAHW3D.c` 의 행별 검사가 **같은 걷기**로 예측한다. 모델이 틀리면
검증기는 **틀린 예측으로 판정한다** — 옳은 배치를 거절하거나 나쁜 배치를
통과시킬 수 있다. 규칙이 고쳐지면 **검증기도 같이 고친다.** 이번 회차에
잊지 않으려고 여기 적는다.

## 7. 성공/실패 기준

- **성공**: 격자 전체에서 화소마다 맞는 규칙을 하나 세우고, 도형 4 와
  이전 세 도형·이전 탐침 세 점을 **동시에** 설명한다.
- **부분**: 어긋나는 영역의 경계를 좌표로 특정한다(예: `mag/dy` 가 어떤 값을
  넘을 때). 그것만으로도 빌더가 그 영역을 피하게 할 수 있다.
- **실패로 적을 것**: 규칙을 못 세우면 못 세웠다고 적고, 그때까지 깊이
  수정과 §3-12 의 나머지를 **보류**한다.

## 8. 이 회차에 안 하는 것

- 깊이 수정(Z2). 보류.
- 빌더 변경. 무엇이 규칙인지 모르는 채 고치면 지난번과 같은 함정이다.
