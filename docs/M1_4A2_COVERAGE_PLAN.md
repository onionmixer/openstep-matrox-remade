# M1-4a2 — 두 래스터라이저의 차이를 넓이가 아니라 **마스크**로 (§3-27)

아직 코드 없음.

## 1. 왜

§3-25 를 고친 뒤 같은 잘린 삼각형이 소프트웨어로 42472, 하드웨어로 42245
화소였다. 나는 그것을 "알려진 커버리지 불일치"라고 적었다.

**그건 논증이지 측정이 아니다.** 넓이 하나로는 이것들을 구분할 수 없다:

- 가장자리 규칙이 반 화소 다른 것 (무해)
- 도형 **속에 구멍**이 있는 것 (결함)
- 잘림이 만든 **삼각분할 이음매**의 불연속 (결함)
- 감는 방향이나 순서에 따라 달라지는 것 (결함)

넓이는 이 넷에 같은 숫자를 낼 수 있다.

## 2. 지렛대는 이미 있다 (확인함)

`OSMGA_MESA_ACCEL=0` 이면 가속이 통째로 꺼진다 — 실기에서 확인했다:
`accelerated 0, surface 0`. 표면을 안 잡으므로 OSMesa 가 애플리케이션
버퍼에 바로 그린다.

가속을 켜면 VRAM 에 그리고 **미러가 같은 애플리케이션 버퍼로 되돌린다.**
그러니 두 경우 모두 **끝은 같은 버퍼**이고 비교가 성립한다.

### 다만 이 관측에는 사각지대가 있다 (확인함)

미러는 정확히 `bufWidth × bufHeight` 만 옮긴다:

```c
w = bufWidth;
for (y = 0; y < bufHeight; y++) {
    const unsigned long *s = src + y * bufStride;
    unsigned long *d = dst + y * bufAppRow;
    for (x = 0; x < w; x++) d[x] = s[x];
}
```

그러므로 **하드웨어가 그 사각형 밖에 쓴 화소는 옮겨지지 않고, 애플리케이션
버퍼만 보는 이 시험에는 안 보인다.** 커널의 클립이 막아야 하는 것이고 별도
가드 시험이 드라이버 쪽에 있지만, "막아야 한다"는 이 세션이 계속 뒤집어온
종류의 문장이다.

**그러니 이 회차의 결론은 "미러되는 사각형 안에서" 라는 단서를 달고 적는다.**
표면 자체를 직접 읽어 바깥을 보는 것은 별개 작업이다.

## 3. 재는 법

한 프로그램이 도형 하나를 그리고 **커버리지를 행별 런으로 찍는다**:

```
row 12: 40-219
row 13: 39-219
```

이것을 두 번 돌린다 — `OSMGA_MESA_ACCEL=0` 과 기본값. **별개 프로세스**여야
한다(표면은 프로세스마다 한 번 잡힌다).

그리고 **python 이 비교한다**:

| 물음 | 어떻게 |
| --- | --- |
| 소프트웨어만 칠한 화소 | 집합 차 |
| 하드웨어만 칠한 화소 | 집합 차 |
| 교집합 | 집합 교 |
| 차이가 가장자리에만 있나 | 차이 화소가 각 행 런의 **양 끝**인가 |
| 속에 구멍이 있나 | 각 행에서 런이 **하나**인가 |
| 이음매가 있나 | 행별 런 경계가 매끄럽게 변하나 |

**출력은 원시 런이고, 유도는 전부 python 에서 한다** — 이 저장소의 방침이다.

## 4. 무엇을 그릴 것인가

한 도형으로는 못 말한다. 넷을 같은 방식으로 잰다:

1. **작고 화면 안에 드는 삼각형** — 잘림도 분해도 없다. 여기서 차이가
   나면 그것은 순수한 가장자리 규칙이다.
2. **§3-25 의 그 삼각형** — 뷰포트를 크게 벗어나 Mesa 가 자른 것. 이음매가
   생기는 경우다.
3. **1 번을 감는 방향만 뒤집은 것** — 커버리지가 방향에 의존하면 결함이다.
4. **1 번을 몇 화소 평행이동한 것** — 차이가 위치에 붙어 다니면 반올림
   규칙이고, 안 붙어 다니면 다른 것이다.

## 5. 무엇이 무해하고 무엇이 아닌가 (미리 적는다)

**미리 적는 이유**: 숫자를 보고 나서 기준을 정하면 무엇이든 통과시킬 수 있다.

- **무해**: 차이가 전부 각 행 런의 첫/끝 화소이고, 폭이 한 화소를 안 넘고,
  각 행의 런이 하나다.
- **결함**: 어느 행이든 런이 둘 이상(구멍), 차이가 런 안쪽에 있음,
  하드웨어만 칠한 화소가 도형 밖에 있음, 3 번이 1 번과 다름.

## 6. 안 하는 것

- **차이를 없애려 들지 않는다.** 이 회차는 그것이 무엇인지 아는 것이다.
  무해하다고 밝혀지면 숫자를 기록하고 닫는다.
- **소프트웨어를 정본으로 가정하지 않는다.** 둘 중 어느 쪽이 GL 의 채움
  규칙에 맞는지는 별개 질문이고, 필요하면 규격을 보고 따진다.
